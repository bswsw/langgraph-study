15장 처럼 모든 도구 호출 앞에서 멈추는 것이 아니라 유연하게 Human-in-the-loop 흐름을 구성한다.

동작 순서
- llm이 HumanRequest 도구를 호출하면 챗봇이 상태의 ask_human을 true로 바꾼다.
- 라우터가 ask_human 값을 보고 human 노드로 보낸다. interrupt_before이 human이기 때문에 그 직전에 멈춘다.
- 사람이 답변을 작성하면 create_response로 ToolMessage로 만들고 update_state로 상태에 추가한다.
- stream(None, config) 로 재개하고 human 노드는 플래그만 끄고 챗봇이 사람의 답을 바탕으로 최종 답을 만든다.

최신 Langgraph 에서는 노드 안에서 interrupt() 로 멈추고 재개할 때 넘긴 값을 노드가 그대로 받는 방식을 많이 쓴다. tool_call_id 매칭과 No Response 방어 로직을 노드 한 곳에 모을 수 있다.

```python
from langgraph.types import interrupt, Command

def human_node(state: State):
    ai_message = state["messages"][-1]
    request = ai_message.tool_calls[0]["args"]["request"]
    answer = interrupt({"request": request})      # 여기서 멈춤, 재개 시 값이 반환됨
    return {
        "messages": [create_response(answer or "No response from human.", ai_message)],
        "ask_human": False,
    }

graph = graph_builder.compile(checkpointer=MemorySaver())   # interrupt_before 불필요

graph.invoke({"messages": [("user", user_input)]}, config)  # → __interrupt__ 반환

graph.invoke(Command(resume="전문가 답변 ..."), config)      # 답변을 넣고 재개
```
