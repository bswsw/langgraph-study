ToolNode는 메시지 목록이 든 그래프 상태를 받아 마지막 AIMessage의 tool_calls를 읽고 해당 도구를 실행한 뒤 그래프 상태를 업데이트하는 LangGraph의 사전 구축 컴포넌트이다.

마지막 메시지가 AIMessage가 아니거나 tool_calls가 비어있으면 ToolNode는 오류를 발생시킨다.

실제로는 AIMessage를 손으로 만들지 않고 bind_tools()로 모델에 도구를 알려주면 llm이 tool_calls가 담긴 AiMessage를 만든다. 만들어진 메시지를 그대로 ToolNode에 넘기면 된다.
llm은 어떤 도구를 어떤 인자로 호출할지 결정하고 ToolNode는 실행만 맡는 관심사의 분리 패턴이 된다.

handle_tool_errors를 true로 설정하면 예외 발생 시 오류 메시지를 ToolMessage로 바꿔 llm에게 전달하고 llm은 오류를 인식해 다른 방법을 시도 한다.
