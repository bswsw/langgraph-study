## 가드레일

### 대표 사례
- 개인정보 유출 방지 (pii)
- 프롬프트 인젝션 공격 탐지 및 차단
- 부적절하거나 유해한 콘텐츠 차단
- 비즈니스 규칙 및 규정 준수 요구사항 강제
- 출력 품질 및 정확성 검증

### 접근 방식
- 결정론적
  - 정규표현식, 키워드 매칭, 명시적 검사
  - 빠름/저비용
  - 미묘한 위반을 놓칠 수 있음
  - 금지어 필터링, pii 패턴 탐지
- 모델 기반
  - LLM 의미론적 이해
  - 느림/고비용
  - 실행 지연, 추가 API 비용 발생
  - 감정 분석, 안정성 평가, 품질 검증

### 내장 가드레일
- PIIMiddleware
- HumanInTheLoopMiddleware

### 커스텀 가드레일
- @before_agent, @after_agent
- AgentMiddleware 클래스 + @hook_config

### 가드레일 결합
- 배열 순서대로 실행되며, 빠른 결정론적 검사를 먼저 배치하고 느린 모델 검사를 나중에 배치하면 불필요한 비용을 줄일 수 있음

### 외부 가드레일
프롬프트 인젝션 탐지
- Lakera Guard — 상용 API. 인젝션·탈옥(jailbreak) 탐지에 특화, 98%+ 탐지율에 50ms 미만 지연을 내세움. 현재는 Check Point AI Security를 통해서도 제공됨
- Meta Llama Guard 3 / Llama Prompt Guard 2 — 오픈 웨이트 모델, 자체 호스팅 가능. 입출력에 안전 라벨을 붙이는 방식
- LLM Guard (Protect AI, MIT 오픈소스) — 데이터를 외부로 보내지 않고 자체 인프라에서 스캐너를 직접 운영하고 싶을 때 적합
- NVIDIA NeMo Guardrails — 단일 요청 스캔보다 멀티턴 대화 흐름 자체를 제어하고 싶을 때
- LlamaFirewall — 에이전트용 오픈소스 가드레일 시스템

유해 콘텐츠 차단
- OpenAI Moderation API — 무료, 혐오·폭력·괴롭힘 등 카테고리별 분류
- Azure AI Content Safety — 유료. 콘텐츠 유해성 심각도 등급, PII 필터링, 환각(hallucination) 탐지까지 포함. 그 안의 Prompt Shields 기능이 프롬프트 인젝션도 함께 탐지함 (인젝션+유해콘텐츠를 한 서비스로 묶고 싶으면 이쪽이 편함)
