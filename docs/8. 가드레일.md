## 가드레일

### 대표 사례
- 개인정보 유출 방지 (pii)
- 프롬프트 인젝션 공격 탐지 및 차단
- 부적절하거나 유해한 콘텐츠 차단
- 비즈니스 규칙 및 규정 준수 요구사항 강제
- 출력 품질 및 정확성 검증

### 접근 방식
- 결정론적
  - 정규표현식, 키워드 매칭, 명시적 검사
  - 빠름/저비용
  - 미묘한 위반을 놓칠 수 있음
  - 금지어 필터링, pii 패턴 탐지
- 모델 기반
  - LLM 의미론적 이해
  - 느림/고비용
  - 실행 지연, 추가 API 비용 발생
  - 감정 분석, 안정성 평가, 품질 검증

### 내장 가드레일
- PIIMiddleware
- HumanInTheLoopMiddleware

### 커스텀 가드레일
- @before_agent, @after_agent
- AgentMiddleware 클래스 + @hook_config

### 가드레일 결합
- 배열 순서대로 실행되며, 빠른 결정론적 검사를 먼저 배치하고 느린 모델 검사를 나중에 배치하면 불필요한 비용을 줄일 수 있음
