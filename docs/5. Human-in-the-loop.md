## 05. Human-in-the-Loop

- after_model 훅을 정의하는 미들웨어의 한 종류이다.
- 결정 타입 (dicision type)
  - approve: 에이전트가 제안한 도구 호출을 그대로 실행
  - edit: 도구 호출 인수를 변경하여 실행
  - reject: 실행을 거부하고 이유를 에이전트에게 피드백
  - 특정 응답 방식만 선택할 수 있도록 제어할 수 있다. 
- 필수 조건
  - checkpointer: 상태를 저장하고 복원하기 위한 저장소
  - 개발에서는 InMemorySaver, 프로덕션에서는 AsyncPostgresSaver 권장
  - `RuntimeError: Cannot use Command(resume=...) without checkpointer`
  - thread_id: 어느 대화/ 상태인지 구분
  - 각 대화 세션에 고유 thread_id를 할당 (UUID)
  - `ValueError: Checkpointer requires one or more of the following 'configurable' keys: thread_id, checkpoint_ns, checkpoint_id`
- 다중 작업 승인
  - 인터럽트 데이터의 action_requests 순서와 일치해야한다.
  - 모델이 프롬프트를 이해하고 생성하는 AIMessage.tool_calls 배열 기준으로 action_requests가 생성된다.
  - 프롬프트의 순서를 변경하면 AIMessage.tool_calls 배열이 변경되는 것을 확인했지만 명세는 아니고 모델에 따라 다를 수 있다.
