# LangGraph를 활용하여 에이전트 구축하기

- 질문에 따라 직접 답하거나 도구를 호출하는 에이전트
- 고정된 흐름의 챗봇이 아니라 도구 사용 여부에 따라 동적으로 동작

## 구성 요소

- 모델 노드(chatbot): 질문을 해석하고 답변 또는 도구 호출을 생성
- 도구 노드(tools): 외부 정보를 실제로 가져옴
- 조건부 에지: tool_calls가 있으면 tools로, 없으면 END로 이동

## 상태와 도구 바인딩

- State: messages 필드에 add_messages 리듀서 적용 → 노드는 새 메시지만 반환하면 자동으로 누적
- bind_tools: LLM에 사용 가능한 도구 목록을 알려줌
  - 도구를 실행하지 않고 도구 호출 요청(tool_calls)만 생성

## 도구 노드

- BasicToolNode: 마지막 AIMessage의 tool_calls를 실행하고 결과를 ToolMessage로 반환
  - tool_call_id로 어떤 호출의 결과인지 매칭
- 프로덕션에서는 오류 처리와 병렬 실행을 지원하는 프리빌트 ToolNode / tools_condition 사용 권장

## 순환 구조

- START → chatbot → (tools | END), tools → chatbot
- LLM이 도구 결과를 보고 다시 판단해 추가 도구 호출 또는 최종 응답
- 조건부 에지는 단일 노드에서 시작해야 함 (chatbot 실행 후마다 route_tools가 다음 노드 결정)
- 프리빌트 tools_condition도 같은 방식으로, 도구 호출이 없으면 "__end__"를 반환

## 메시지 흐름

- HumanMessage → AIMessage(tool_calls) → ToolMessage → AIMessage(최종 답변)
