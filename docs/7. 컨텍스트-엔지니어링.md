## 07. 컨텍스트 엔지니어링

### 컨텍스트의 종류
- 모델 컨텍스트
  - 일시적
  - 단일 LLM 호출
  - @dynamic_prompt: 런타임에 시스템 프롬프트를 동적 생성
  - @wrap_model_call: 메시지, 도구, 모델, 응답형식을 request.override로 수정
- 도구 컨텍스트
  - 영구적
  - 상태, 스토어 읽기/쓰기
  - 도구가 엑세스, 생성하는 모든 데이터
  - 도구 함수에 ToolRuntime 매개변수로 주입 받을 수 있음
  - Command(update={..}): 상태 업데이트
  - runtime.store.put(..): 스토어 업데이트
- 라이프사이클 컨텍스트
  - 영구적
  - 단계 사이 훅
  - 요약, 가드레일, 로깅 등 교차 관심사 제어

### 데이터 소스
데이터 소스를 잘못 고르면 정보 범위가 맞지 않거나 불필요한 데이터가 전달되어 성능이 저하될 수 있음
- 런타임 컨텍스트
  - 정적 구성
  - 대화 범위
  - 사용자 ID, API 키, DB 연결, 권한
- 상태
  - 단기 메모리
  - 대화 범위
  - 현재 메시지, 업로드된 파일, 인증 상태
- 스토어
  - 장기 메모리
  - 대화 간 공유
  - 사용자 선호도, 추출된 인사이트, 기록
